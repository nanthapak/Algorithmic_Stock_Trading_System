# ALGORITHMIC STOCK TRADING SYSTEM

I learned how to trade stocks from my dad, and when I did some research, I discovered things called technical indicators.
They are tools calculated from stock data which are very powerful if you use them wisely, but there are so many of them.
This made me think: what if I created an algorithm that makes decisions based on the data? Wouldn't that be very powerful?
So I built this project with my friend, and it turned out to be very good and won multiple awards.

Automatically generates trading signals (Buy/Sell/Hold) through optimization using Differential Evolution Algorithm.
The parameters of the optimization algorithm are the weights of well-known technical indicators such as RSI, MA, and MACD, along with some other self-researched ones.

**Codes** - Contains all of the code from creating technical indicators to training the model.
**Paper** - Contains research papers, certificates, and awards of the project.
**Streamlit** - Contains website code.
